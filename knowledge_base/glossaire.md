# Glossaire F1 — Définitions & Acronymes

Version: 2026-01-12
Auteur: Projet AIBot
Sources: FIA, Formula1.com, Wikipedia

- **FIA**: Fédération Internationale de l’Automobile (régulateur F1)
- **DRS**: Drag Reduction System (réduction traînée pour dépassement)
- **ERS/KERS**: Energy Recovery System / Kinetic Energy Recovery System
- **PU**: Power Unit (unité de puissance hybride: moteur thermique + électrique)
- **WDC/WCC**: World Drivers’/Constructors’ Championship (titres pilotes/constructeurs)
- **Pole**: Pole position (première place sur la grille)
- **Out/In-lap**: Tour de sortie/entrée (pit)
- **Undercut/Overcut**: Stratégies d’arrêt pour dépasser via timing
- **Parc Fermé**: Règles de parc fermé (restrictions de réglages après qualif)
- **Sprint**: Format court (qualif/course sprint selon calendrier)
- **Safety Car/Virtual SC**: Voiture de sécurité/SC virtuelle
- **Pit Window**: Fenêtre d’arrêts aux stands prévue

Notes: définitions simplifiées; se référer au règlement FIA pour détails techniques.
